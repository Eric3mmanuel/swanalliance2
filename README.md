# Swan Alliance Limited — Website Starter

A responsive five-page static website built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About Swan Alliance
- `services.html` — Services
- `global-network.html` — Office contacts / global connections
- `contact.html` — Contact details and enquiry form

## Run locally
Open `index.html` in a browser. For best results, use a simple local web server or deploy the folder to a static host.

## Important before publishing
- The supplied Swan Alliance logo is included in `assets/`.
- The enquiry form currently prepares an email using the visitor's email application (`mailto:`). It does not store or submit form data to a server.
- Replace the stock logistics photographs with company-owned photographs where possible.
- Confirm all service descriptions, office locations, business hours, legal details, routes, capabilities, and any claims with Swan Alliance before publishing.
- No certifications, guaranteed delivery times, live tracking, warehouse capacity, or specific shipping routes have been invented.
- Fonts and stock photography are loaded from external services and require an internet connection.
